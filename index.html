ℹ️ How to Use

1. Create a list

On the home screen, type a list name (e.g. "Week 1") and tap + to create it.

2. Add words

Open a list and add each spelling word. Tap "🔍 Look Up Definition" to auto-fill meanings.

3. Practice

Tap 📖 Practice to hear each word and type its spelling with instant feedback.

4. Test

Tap 📝 Test to take a full quiz and get a score at the end.

5. Navigate

Use the ← back arrow (top left) to go back one screen. Use Profile to change avatar or name.

6. Dark mode

Tap 🌙 / ☀️ in the top right to switch between light and dark themes.
